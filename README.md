# 🍽️ FRESH FOOD – RESPONSIVE RESTRAURANT WEBSITE
> A modern, fully responsive restaurant website built using HTML, CSS, and JavaScript, designed to deliver an engaging user experience through clean UI design, intuitive navigation, and mobile-friendly layouts.
---

## 🌟PROJECT OVERIEW
Fresh Food is a frontend-focused restaurant website that showcases a complete restaurant experience through an attractive and responsive user interface.
The project was developed to strengthen frontend development skills, responsive web design principles, and UI/UX practices while creating a realistic business website.
The website is optimized for various screen sizes and provides users with a seamless browsing experience across desktops, tablets, and mobile devices.

---
## 🎯 PROJECT OBJECTIVE
* Build a complete restaurant website from scratch
* Practice responsive web design
* Improve UI/UX design skills
* Create reusable and maintainable frontend components
* Enhance JavaScript fundamentals through interactive features
* Simulate a real-world restaurant business website
