---

## 🌟PROJECT OVERIEW
Fresh Food is a frontend-focused restaurant website that showcases a complete restaurant experience through an attractive and responsive user interface.
The project was developed to strengthen frontend development skills, responsive web design principles, and UI/UX practices while creating a realistic business website.
The website is optimized for various screen sizes and provides users with a seamless browsing experience across desktops, tablets, and mobile devices.

# 🎮 ROCK PAPER SCISSOR IN JAVA

> A console-based Rock Paper Scissors game built in Java showcasing the evolution from basic programming concepts to Object-Oriented Programming (OOP) and Exception Handling.
![Java](https://img.shields.io/badge/Java-17+-orange)
![OOP](https://img.shields.io/badge/OOP-Implemented-blue)
![Exception%20Handling](https://img.shields.io/badge/Exception-Handling-green)
![Status](https://img.shields.io/badge/Status-Completed-success)
---
## 📖 OVERVIEW

This project is a command-line implementation of the classic **Rock Paper Scissors** game where a player competes against a computer-generated opponent.
The repository demonstrates a structured learning journey through three progressively improved versions of the same application.
Instead of focusing solely on the final solution, this project highlights how software can evolve through refactoring, better design principles, and improved error handling.
---
## 🚀PROJECT EVOLUTION

### 🔹 VERSION 1 – Basic Implementation
A beginner-friendly implementation using:
* Scanner for user input
* Random class for opponent selection
* If-Else statements
* Switch-case logic

#### Concepts Practiced
* Variables
* Conditional Statements
* User Input Handling
* Random Number Generation
---
### 🔹 VERSION 2 – Object-Oriented Programming
Refactored the project using OOP principles.

#### Improvements
* Introduced `Game` class
* Added `Choice` enum
* Modularized logic into methods
* Improved readability and maintainability

#### Concepts Practiced
* Classes & Objects
* Methods
* Enums
* Encapsulation
* Code Organization
---
### 🔹 VERSION 3 – Exception Handling
Enhanced user experience through robust input validation.

#### Improvements
* Custom `InvalidChoiceException`
* Input validation
* Try-Catch exception handling
* Better error messages
* Improved application reliability

#### Concepts Practiced
* Exception Handling
* Custom Exceptions
* Defensive Programming
* Error Recovery
---

| Rock          | Scissors |

**Elite Canine** is a modern UI/UX design prototype for a dog magazine and breed discovery platform. The project focuses on creating an engaging, clean, and user-friendly experience for dog enthusiasts to explore breeds, read articles, compare dogs, and discover canine-related content.
This project was designed entirely in **Visily**, emphasizing intuitive navigation, consistent design, and modern UI principles.
